### How the Compiled Netlist Needs an MCU Element

Currently, the MCU compiles to a comment line in the SPICE netlist. To simulate the behavior of an Arduino pin, we need to add an MCU element to the netlist. This can be achieved by adding a new component to the netlist that represents the Arduino pin.

**Example Code:**
```python
def add_mcu_element(netlist, pin_number):
    netlist.add_component("ARDUINO_PIN", pin_number, 0, 0, 0, 0)
    netlist.add_pin("ARDUINO_PIN", "IN", 1)
    netlist.add_pin("ARDUINO_PIN", "OUT", 1)
```

### Proposing the Exact SPICE Modeling of a GPIO Pin

An Arduino pin can be modeled as a simple voltage source that can be controlled by the firmware. Here is a proposed SPICE model for an Arduino pin:

- **V2**: A voltage source to set the pin's output level.
